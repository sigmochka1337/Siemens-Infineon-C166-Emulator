#Регистры
Регистры - одна из главных основ языка ассемблера. Это специальные ячейки памяти, находящиеся в самом процессоре. именно регистры используются для комманд процессора.  Регистры бывают следующих типов:
1. регистры общего назначения: AX, BX, CX, DX, BP, SI, DI, SP.
2. сегментные регистры: CS, DS, SS, ES.
3. счетчик коммнад: IP.
4. регистр флагов: Flags. 
#Исполнение ассемблера
rip - регистр-указатель на следующую инструкцию.
#Цикл выполнения:
1. fetch - CPU читает байты по адресу из rip.
2. decode - декодирует инструкцию и определяет ее длину.
3. execute - выполняет операцию.
Основные инструкции
инструкция	Что делает
Mov DEST, SRC	Копирует занчение из SRC в  DEST
Sub DEST, SRC	Вычитает SRC из DEST
Add DEST, SRC	Складывает DEST и SRC
Imul DEST, SRC	Знаковое умножение

#Соглашения (конвенции) о вызовах
Соглашение о вызовах - это набор правил, по которым функции передают друг другу управление и данные. Оно определяет:
1. где передаются аргументы;
2. в каком порядке;
3. где возвращается результат;
4. какие регистры функция обязана сохранить;
5. как выравнивать стек;
6. как очищать стек после вызова.
#Секции
Cекция - именованная область объектного файла для кода, данных или резерва.
секции	Для чего
.text	Находится исполняемый код программы
.data	Лежат инициализированные глобальные переменные
.bss	Лежат неинициализированные глобальные переменные
.rodata	Содержит константы
.got	Хранит адреса

#Линковка
линковка - процесс связывания объектных файлов и библиотек в один исполняемый файл. Линкер объединяет секции, выполянет релокации, разрешает символы.
Что делает линкер
1. объединяет несколько объектных файлов в один;
2. разрешает символы - связывает extern из одного модуля с global из другого;
3. объединяет одноименные секции по разным файлам;
4.  размещает секции ро адресам и формирует сегменты с праввами доступа;
5. выполняет релокации — подставляет реальные адреса вместо заглушек;
6. подключает библиотеки - статические или динамические.
*Статические библиотеки — это наборы объектных файлов (.a), код которых при линковке копируется прямо в исполняемый файл, поэтому программа самодостаточна, но файл получается больше.
Динамические библиотеки — это разделяемые библиотеки (.so), код которых не копируется в файл, а подключается при запуске программы динамическим линкером, поэтому файл меньше, но программа зависит от наличия библиотеки в системе.
